КАРТА МАРШРУТА — ПЕРЕНОСИМАЯ ВЕРСИЯ
=====================================

Установка не требуется.

ЗАПУСК
1. Полностью распакуйте ZIP-архив в отдельную папку.
   Не запускайте START.bat прямо из окна ZIP-архива.
2. Дважды щёлкните файл START.bat.
3. В открывшемся окне браузера нажмите «Открыть JSON-файл».
4. Выберите нужный файл .json или .geojson.

Если START.bat не запускается, откройте RouteMap.html напрямую в Microsoft Edge,
Google Chrome или Firefox. JSON-файл можно перетащить на карту мышью.

ИНТЕРНЕТ
JSON обрабатывается только на компьютере и никуда не передаётся.
Интернет нужен для загрузки подложки Google или OpenStreetMap.

СОСТАВ ПАКЕТА
START.bat          — запуск просмотрщика
RouteMap.html      — приложение
example-route.json — пример маршрута для проверки
README.txt         — эта инструкция

Если карта не появилась, проверьте доступ к google.com в браузере
или корпоративном брандмауэре.
